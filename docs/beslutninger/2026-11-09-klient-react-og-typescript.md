# Klienten er en webapp i React og TypeScript

- **Dato:** 9. november 2026
- **Status:** gjelder

## Beslutning

Klienten er en webapp i React og TypeScript, med hash-ruting.

## Følger

- Ruting: `createHashRouter`, eller `createMemoryRouter` når appen bygges med `VITE_ROUTER=memory` (`src/app/App.tsx`).
- Kilde: «Antakelser» i [AVVIK.md](../AVVIK.md).
