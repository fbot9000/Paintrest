# Ett dokument per tema

- **Dato:** 24. november 2026
- **Status:** gjelder

## Beslutning

Dokumentene ryddes, slik at hvert tema har ett sted. Før dette sto status tre steder (README, AVVIK og BIT7), og AVVIK blandet avvik, beslutninger, antakelser og gjøremål. Det ga motstridende informasjon.

| Tema | Dokument |
|---|---|
| Regler for agenter | `CLAUDE.md` |
| Arbeidsflyt | `docs/PROSESS.md` |
| Oppgaver | `docs/OPPGAVER.md` |
| Hva som er bygget | `docs/STATUS.md` |
| Beslutninger | `docs/beslutninger/`, én fil per beslutning |
| Kildedokumentene | `docs/kilder/` |
| Avvik fra kildedokumentene og antakelser | `docs/AVVIK.md` |
| Hvordan appen virker | `docs/BRUKERVEILEDNING.md` |
| Kode, lagring og nøkler | `docs/ARKITEKTUR.md` |

Beslutninger får hver sin fil med datoen i navnet, slik at to agenter ikke gir to beslutninger samme nummer.
